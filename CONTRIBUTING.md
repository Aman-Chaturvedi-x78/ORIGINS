# Contributing

Thanks for your interest in contributing to this project! A few simple guidelines:

- Fork the repository and create a feature branch from the default branch.
- Keep changes focused and small; open one pull request per logical change.
- Use clear, descriptive commit messages.
- For content changes (HTML/CSS), prefer semantic HTML and add comments where helpful.
- If you add JavaScript, try to keep it unobtrusive and progressive (works without JS when possible).

Reporting issues

- Open an issue with a clear title and steps to reproduce if relevant. Attach screenshots when helpful.

Code style

- HTML: use lowercase tags and attributes, indent with 2 spaces.
- CSS: organized and prefixed where necessary; consider using a consistent ordering.

Thanks — maintainers will review PRs as time permits.
